# CS452 K1

There are no special requirements to build the program beyond running `make` on the `linux.student.cs` environment, which generates the image at `kitty_kernel.img`.

Once the program is loaded and executed on the RPi, a welcome message starting with `Kitty kernel version` is printed from the kernel, and the required user task is immediately run. Upon the exit of all user tasks, the kernel prints `All tasks exited. Press any key to reboot...` and waits for a key press to reboot. All other output is generated by the user task.
